# Contributing

This repository is the published monday.com plugin for Google Antigravity. Its contents are generated
by monday.com's release process, so pull requests here are not merged directly.

- **Skills** (`skills/`) come from [mondaycom/skills](https://github.com/mondaycom/skills). Open skill
  issues and pull requests there.
- **Anything else** (manifest, README, rules, MCP configuration): open an issue in this repository.
- **Product support:** [support.monday.com](https://support.monday.com).
