# monday.com

Bring monday.com into Antigravity. Create, update and assign items, write docs and set up forms without
leaving your editor.

## What you get

- **monday.com MCP server** - the official monday.com MCP server (`https://mcp.monday.com/mcp`), with tools
  for boards, items, columns, docs, forms, dashboards, workspaces and more.
- **Skills**
  - `/onboard-to-monday` - first-run setup: builds a board tailored to your work, with starter items and an automation.
  - `/task-management` - create, update, assign and move items, with correct column-value formats.
  - `/docs-collaborator` - create, read, edit and comment on monday docs, including live column embeds and mentions.
  - `/forms-builder` - create, edit and publish monday WorkForms.

## Getting started

1. Install the plugin from **Customizations → Plugins** in Antigravity, or from the terminal:
   `agy plugin install https://github.com/mondaycom/antigravity-plugin`
2. On first use, sign in to monday.com in the browser window that opens and approve access.
3. Try a starter prompt, or ask something like "Mark the 'Login bug' item on my Sprint board as Done"

You only get access to what your monday.com user can already see. Account admins can manage AI connector
access in **Administration → AI governance → AI permissions**.
